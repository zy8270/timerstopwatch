# ui/widgets/ — 复用组件

| 文件 | 职责 | 影响 |
|------|------|------|
| `cycling_wheel.dart` | 循环数字滚轮（`ListWheelChildLoopingListDelegate`，远离中点无感回中）。**每滚过一格：`onSelectedItemChanged` → 原生 `wheelTick` 并同步圈基；滚动中零重建**；值提交只在滚动停止（ScrollEnd）的 `onChanged`。v3.6 两处关键口径：①SDK 对循环列表的 `onSelectedItemChanged` 回调**归一化序号**（raw%count），圈基必须从 `controller.selectedItem`（原始圈位）同步；②程序化跳转（应用预设/回中）期间（`_programmatic`）派发的滚动通知一律不处理——`jumpTo` 内部 `goIdle()` 会先派发一条携带滞留位置的结束通知，不拦会把旧值提交回去覆盖预设。外部设值走 `syncGen` 整组代数：值没变的滚轮（可能在惯性滚动中）也要归位；手指按住时等松手再应用。**v3.11：自己提交的回声不算外部设值**（按 `_syncedValue` 最近同步值识别）——连拨时回声常在手指已再次按下时到达，误判会让滚轮停止时闪回上一拨的落点 | 计时页时长选择的唯一输入件；单位小字"时/分/秒"由 timer_page 排在轮间并与中行对齐 |
| `analog_clock.dart` | 圆形时钟（v3.11，时钟样式=analog 时的倒计时显示）：CustomPaint 表盘——外圈剩余比例弧（12 点起顺时针覆盖、随倒计时消耗）+ 60 刻度（每 5 格主刻度）+ 时/分/秒指针 = **剩余时长的表盘读数**（剩 1:30:00 指针指 4:30 位置，随倒计时回退、归零三针向 12）+ 中心剩余数字（指针看趋势、数字读秒）。颜色三参（前景/弧底/弧与秒针）可注入暗色形态 | 计时页进行/暂停/结束态与假睡眠层共用；改表盘观感只改本文件的 painter |
| `fake_sleep_layer.dart` | 伪熄屏覆盖层：纯黑全屏 + 时间文字（alpha 0.5）+ 暂停小字；每 45 秒随机**跳变**防烧屏；点击后非线性动画回位再退出。**必须在 Material 祖先下渲染**（本组件自带透明 Material + 显式 `decoration: TextDecoration.none`）：v3.6 定案黄线根因是本层原挂在 Scaffold 之外、无 Material 祖先时被 MaterialApp 注入黄色双下划线 fallback 样式，与 OLED 无关。**v3.11：跟随时钟样式切换**——analog 时显示 `AnalogClock` 全白 50% 暗色形态（文字仍显式去装饰线） | 黑底 OLED 不发光，暗字即可营造伪熄屏；若嫌暗/亮改文字 alpha 一处 |
| `mark_edit_dialog.dart` | 标记编辑对话框（v3.6 新增）：修改剩余时间节点（`parseClockInput` 解析 h:mm:ss / mm:ss / 秒数，校验 ≤ 总时长）与备注、删除该条。计时页与历史页共用；改剩余时间后已进行按 总时长-剩余 重算 | 标记"时间+备注"编辑的单一入口，两页行为天然一致 |
| `app_icon.dart` | App 图标绘制源：配色深→亮对角渐变底（**圆角矩形，半径=边长 20%——v3.13，部分桌面不走 adaptive 遮罩直接取位图，位图必须自带圆角**）+ 白色扁平秒表（表盘+顶帽+斜放沙漏，**按包围盒视觉居中**）；渐变颜色取 `palette` 参数（`AppPalette`，v3.12 主题联动，默认深紫为 v3.3 原始配色）。`test/icon_golden_test.dart` 用它渲染各配色×各密度的 PNG 资源（adaptive 前景为白色图形、各配色共用一份，透明无圆角） | 改图标只改这里然后重新导出，不要手改 res 下的 PNG；设置页配色弹窗直接复用本组件作选项图标（所见即所得） |
