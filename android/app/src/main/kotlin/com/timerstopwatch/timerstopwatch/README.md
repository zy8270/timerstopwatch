# kotlin/com.timerstopwatch.timerstopwatch/ — Android 原生实现

| 文件 | 职责 | 影响 |
|------|------|------|
| `MainActivity.kt` | MethodChannel `timerstopwatch/app` 的注册中心：响铃/提示音/考试音频 ensureExamAudio/滚轮反馈/前台服务/悬浮窗/权限/勿扰/亮度/音频导入/**桌面图标切换 setIcon（v3.12：按 `ICON_KEYS` 启停 `alias_<key>`；**先启用目标再禁用其余**、键大小写不敏感、未知键回落 lightpurple；Dart 侧延迟到应用退后台才调——前台禁用任务基座 alias 会被部分 ROM（iQOO 实测）结束应用，v3.13）**全部在此分发；持有 `dartChannel` 供广播回调反向调 Dart | 新增原生方法在这里加 case；音频导入拷贝到应用私有目录 |
| `TimerService.kt` | 前台服务：运行模式常驻通知（剩余 + 距上次标记 + 「标记」action，每秒刷新）+ AlarmManager.setAlarmClock 精确兜底；每秒把 `剩余/总时长` 推给悬浮窗（`OverlayWindow.update`），暂停/继续时同步 `setPaused`（悬浮窗药丸文案随之切换「继续计时」/「返回计时器」）；响铃模式（结束/被杀拉起）全屏通知；结束/销毁时隐藏悬浮窗；**通知小图标 = `ic_notification`（白色秒表剪影，与 App 图标同造型）** | 后台/锁屏/杀进程三条响铃路径的枢纽 |
| `AlarmRing.kt` | MediaPlayer 循环响铃（USAGE_ALARM 声道，勿扰下可响）+ 波形震动；一次性提示音（阈值提醒） | 铃声行为的唯一实现 |
| `OverlayWindow.kt` | 后台倒计时悬浮窗（v3.15~21 八轮打磨）：行布局 [标记(圆角半透明底) \| 时间槽 \| ✕(竖直居中、右侧空间正中)]，**整窗单一触摸处理器**（任何位置可拖，松手按屏幕坐标命中分发）；点时间→**Z 轴悬浮盖住时间**的胶囊按钮（窗口不动、**2 秒自动收起**；运行中=「返回计时器」点击拉起应用，**暂停中=「继续计时」**点击经 dartChannel 回调 Dart resume）；**贴边交互**：拖动中距边 ≤10px 时整个窗口内容原地变纵向进度条预览（上灰=已流逝、下彩=剩余），松手收起为贴边条（高=悬浮窗高、宽=标记按钮高）；**贴边条拖离边缘即原地长回悬浮窗**（朝屏幕内侧生长、围绕手指，贴边那侧不跳；本手势内松手不再判定吸附）；点击条→**单段对称缓动展开**（AccelerateDecelerate + 宽/高/位置四元同帧补间 + 条淡出与窗淡入交叉过渡——v3.20 修掉"先长成满宽窗、再挪一小步、末尾停顿"）；**位置记忆（v3.21）**：拖动落点存 SharedPreferences（`overlay_window` 的 pos_x/pos_y），下次弹出还原，**仅自由放置才记录**（拖到边缘收起不覆盖）；首次默认**水平居中、竖直中心=屏幕 3/4 高度**（须补 `statusBarInset`：覆盖层 y 相对状态栏下方父区域）；窗口补间用 Choreographer 自驱动（**勿用 ValueAnimator**：覆盖层环境 18ms 即 end；**勿用回调 time 算进度**：vsync 时基不同，首帧即 t=1）；tweenToken 哨兵管取消；填充=方形色块经圆角遮罩、底部锚定、颜色 绿→黄→红 连续渐变；数据 `update(剩余,总时长)` 每秒由 TimerService 推送（`setPaused` 同步暂停态） | 需要 SYSTEM_ALERT_WINDOW；调试钩子=debug 包长按计时页标题（左对齐），input swipe 长按偶发不中需重试；**贴边条极窄（宽=标记按钮高）易与系统返回手势冲突**，模拟器验证拖离行为须先切三键导航（`cmd overlay enable-exclusive --category com.android.internal.systemui.navbar.threebutton`）；**arm64 包装不进 x86 模拟器**（UnsatisfiedLinkError），模拟器用 `--target-platform android-x64`，交付用 `android-arm64 --split-per-abi` |
| `WheelFeedback.kt` | **滚轮逐格反馈**：线性马达 `VibrationEffect.EFFECT_TICK`（API 29+，低版本弱震动兜底）+ SoundPool 播放 `res/raw/wheel_tick.wav`（USAGE_ASSISTANCE_SONIFICATION 跟随系统音量） | 音效文件由 `tool/gen_tick.dart` 生成，勿手改二进制 |
| `DndHelper.kt` | 勿扰：会话开始保存原状态并开优先级勿扰、响铃前临时解除开关、**会话恢复重启（`sessionRestart`：先复位"全部"再接管，防杀进程后勿扰卡死）**、结束恢复 | 依赖清单里的 ACCESS_NOTIFICATION_POLICY 声明（缺声明则系统勿扰列表不显示本应用，Android 16 实机验证） |
| `ExamAudio.kt` | **考试模式音频（v3.10）**：随包 Flutter assets（`audio/*.m4a`）经 `getLookupKeyForAsset` 拷到私有目录（固定名覆盖写，换包自动更新），返回 key(start/mid15/end)→路径 | 考试三个音频的唯一来源；改文件名须同步 pubspec assets 与 Dart 侧 key |
| `Receivers.kt` | 三个广播接收器：精确闹铃到点拉起响铃服务；通知「标记」转发 Dart；通知「关闭铃声」停声停服 | 通知按钮与悬浮窗标记共用 MarkActionReceiver |

> 资源：`res/raw/wheel_tick.wav` 滚轮音效；`res/drawable/ic_notification.xml` 通知小图标（白色秒表剪影，与 App 图标同造型）；`res/mipmap-*` 图标（由 golden 测试导出，**每套配色一套 `ic_launcher_<key>` + 共用前景 + 基础 `ic_launcher` 取默认配色——v3.12**）；`res/drawable/ic_launcher_bg_*.xml` 各配色渐变底；`AndroidManifest.xml` 权限、服务/接收器注册与 **7 个桌面入口 `activity-alias`（清单默认启用 lightpurple，覆盖安装后 alias 重置，Dart 启动时按持久化配色重设）**。
